# OjoAlSol

OjoAlSol is a React web application starter for discovering the best nearby places to watch the sunset.

## Tech stack

- [React](https://react.dev/)
- [Vite](https://vite.dev/)

## Getting started

```bash
npm install
npm run dev
```

The development server runs at `http://localhost:5173` by default.

## Available scripts

- `npm run dev` - start local development server
- `npm run build` - create a production build in `dist/`
- `npm run preview` - preview the production build locally
- `npm run lint` - run project lint checks

## Project structure

```text
src/
  components/      # Reusable UI pieces for landing and future features
  data/            # Static data placeholders (roadmap, future config)
  App.jsx          # Main page composition
  App.css          # Landing page styles
  index.css        # Global styles
```
